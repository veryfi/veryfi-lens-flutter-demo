# W-2

Cloud extraction of a W-2. One document type. Stitch off. Gallery and a Files button on, because users often photograph or import the form. Backup off.

## Binary support

| Platform | Support |
|----------|---------|
| Android Full | `W2` is allowed (not on native Lite; this plugin is not Lite) |
| iOS Full | Embedding in `veryfi-lens-spm` from `3.0.19` is **Unconfirmed**. Contact support before shipping |

No W-2 Flutter package. Do not add `veryfi-lens-w2-sdk`.

## Settings

```javascript
var settings = {
  ignoreRemoteSettings: true,
  backupDocsToGallery: false,
  backupDocsToiCloud: false,
  moreSettingsMenuIsOn: false,
  moreMenuIsOn: false,
  autoCaptureOtherIsOn: false,
  showNoDocumentDetectedWarning: false,
  dictateIsOn: false,
  locationServicesIsOn: false,
  glareDetectionIsOn: false,
  enableScreenshots: true,

  dataExtractionEngine: 'api',
  documentTypes: ['w2'],
  showDocumentTypes: false,
  autoCaptureIsOn: false,
  stitchIsOn: false,
  galleryIsOn: true,
  browseIsOn: false,
  showBrowserButton: true,
  autoRotateIsOn: true,
  cleanBorderIsOn: true,
  returnStitchedPDF: true
};
```

`returnStitchedPDF` still requests a PDF of what was captured. `stitchIsOn` stays false so Lens does not run the receipt stitcher.

## Wire-up

[full.md](full.md). `"api"` only. Success `status` `"done"`, `msg` `"results"`, fields in `data`. Handle iOS `fail` and Android `failed`.

Photo library usage is required (`galleryIsOn`). Location stays off.

If the host must keep the image after the callback, set `autoDeleteLocalResourcesAfterProcessing: false`. `clearLensStorage()` is not bridged.

## Do not

- Use `"mobile"`
- Use the W-9 template for a W-2. The type string is the model selector
- Turn on `moreMenuIsOn` to get Browse. `showBrowserButton` is the Files control
