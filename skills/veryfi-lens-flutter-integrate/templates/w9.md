# W-9

Cloud extraction of a W-9. Same capture shape as [w2.md](w2.md) with `documentTypes: ['w9']`.

## Binary support

| Platform | Support |
|----------|---------|
| Android Full | `W9` is allowed |
| iOS Full | Embedding in `veryfi-lens-spm` from `3.0.19` is **Unconfirmed**. Contact support before shipping |

No W-9 Flutter package. Do not add `veryfi-lens-w9-sdk`.

Picker hidden. One type. Review is the native camera flow with auto-capture off, so the user presses the shutter. Cloud engine. Files button on, More menu off, backups off.

## Wire-up

[full.md](full.md). The callback is a map, not a JSON string. Cloud success uses `status` `"done"`. iOS failure status is `fail`. Android failure status is `failed`. Image paths on update: read the file at `data`.

## Do not

- Point a W-2 image at `w9` or the reverse
- Set `dictateIsOn`
- Promise Remote Models or Lite. W-2 and W-9 are not on native Lite either, and Lite is not this plugin
